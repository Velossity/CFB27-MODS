# CFB27 game paths (Windows)

Reference paths for modding and tooling. Adjust username as needed.

## Saves

```
%USERPROFILE%\Documents\College Football 27\Saves\
```

Common extensions: `.sav`, `.bin`, `.mc02`

## Tracker (separate project — do not use for mods)

```
%USERPROFILE%\Documents\CFB27 Tracker\
  Dynasties\
  Logos\
  Saves\
```

## Steam install (typical)

```
C:\Program Files (x86)\Steam\steamapps\common\EA SPORTS College Football 27\
```

Exact layout varies by platform and updates. Document discovered paths in your mod's README when you find asset locations.

## Backups

Recommended layout for local work (gitignored):

```
CFB27-Mods/
  game-files/          # optional local mirror — never commit
    saves-backup/
    extracted/
```

Copy saves here before running any experimental tool.
