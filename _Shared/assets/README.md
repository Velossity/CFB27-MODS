# Shared assets

Drop reference images, logos, color palettes, and source files here for reuse across mods.

**Per-mod** art belongs in that mod’s own `assets\` folder. **Finished Frosty packs** belong in that mod’s `mods\` folder (not here).

Suggested subfolders:

- `logos/` — PNG/SVG team marks
- `uniforms/` — reference screenshots or texture sources
- `palettes/` — team color JSON or notes
- `reference/` — era photos, roster sheets, etc.

Team Builder packs stay in `Desktop\Teambuilder Stuff` unless you deliberately mirror references here.

Do not commit copyrighted game rips unless you have rights to redistribute.
